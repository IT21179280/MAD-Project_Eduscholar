# EduScholar – Scholarship Management App

**University Group Project | Android Application**

## About the Project

EduScholar is a simple Android application designed to manage scholarship-related information based on student requirements. The application provides a platform for managing users, courses, and scholarship details.

The application was developed using Kotlin with SQLite as the local database.

## My Contribution – User Management Module

As part of this university group project, I was responsible for developing the **User Management Module**.

Implemented features:

- Add new users.
- View user details.
- Update existing user information.
- Delete user records.
- Store and manage user data using SQLite.

## Main Modules

- **User Management** – Manage user information.
- **Course Management** – Manage course details.
- **Scholarship Management** – Manage scholarship information.
- **Student Requirements** – Manage student-related scholarship requirements.

*My main contribution was the User Management module.*

## Technologies Used

- **Programming Language:** Kotlin
- **Platform:** Android
- **Database:** SQLite
- **IDE:** Android Studio

## Application Features

- Simple Android user interface.
- Local database management.
- CRUD (Create, Read, Update, Delete) operations.
- Basic data management functionality.
